# Cocos Performance Inspector

用于 **Cocos Creator 3.8.x 本机浏览器预览**的性能监控与内存分析插件。打开预览即可自动采集，在编辑器中查看帧率、帧耗时、内存趋势和对象生命周期，并导出离线报告，帮助排查卡顿、资源加载异常和监听器累积等问题。

## 主要功能

- **性能趋势**：查看 FPS、帧耗时和长帧数据，定位持续低帧与偶发卡顿。
- **内存观察**：查看可用的 JS 堆内存与引擎设备统计，观察重复操作后的内存变化。
- **对象快照**：比较 Node、Component、Tween 和事件监听器，查看对象数量、路径及已销毁目标等线索。
- **资源追踪**：记录资源加载、释放和引用操作，结合调用栈查找操作来源。
- **分析报告**：汇总异常线索，导出可独立阅读的 HTML 报告，或使用 JSON 保存、导入采集数据。

实时采集采用增量传输：新增样本和资源事件按批次发送，快照明细分块发送并在确认后复用，编辑器负责合并数据和分析。面板按需加载快照与资源明细，导出时再组装完整报告。

## 安装

1. 解压 `cocos-performance-inspector.zip`，将其中的同名文件夹放入游戏项目的 `extensions` 目录。
2. 在 Creator 扩展管理器中刷新并启用插件。
3. 打开 **扩展 → 性能监控与内存分析**。
4. 启动本机浏览器预览；如果预览已经打开，刷新一次页面。

```text
游戏项目/
  assets/
  extensions/
    cocos-performance-inspector/
      package.json
      dist/
      static/
      PITemp/
```

安装包包含已构建的插件文件，可直接使用。采集会自动接入浏览器预览，无需挂载场景组件、安装游戏 SDK 或填写连接信息。插件不修改项目资源与场景文件，切换场景时会继续采集。

## 开始分析

1. **查看总览**：确认面板出现在线会话，运行游戏并观察帧率、帧耗时、内存曲线及分析发现。
2. **取得基线**：完成资源预热，回到稳定的业务界面，点击“拍摄快照”。
3. **重复操作**：重复进入 / 返回场景、打开 / 关闭界面或进行多局游戏，等待异步任务与延迟销毁完成。
4. **比较快照**：回到相同业务状态，再拍摄快照，在“对象与快照”中选择前后记录，检查对象和监听器的变化。
5. **查看资源与报告**：在“资源生命周期”中检查加载和引用操作，按需导出 HTML 或 JSON。

每次刷新预览页面会开始新的采集会话，可从面板顶部切换会话。快照需要等待运行时响应，确认快照列表出现记录后再进行比较或导出。

快照较大时会分批传入编辑器，完整接收后显示在列表中。已接收的数据保留在编辑器当前会话内，预览断开后仍可查看与导出；采集历史受缓冲区上限约束，超限情况会在报告中说明。

## 采集设置

展开面板中的“自动接入与采集设置”即可调整：

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 采样间隔 | 1000 ms | 控制趋势数据的采样频率，支持 250–10000 ms |
| 记录调用栈 | 关闭 | 排查资源操作和事件注册来源时开启，会增加采集开销 |

点击“应用设置并开始新会话”后，在线预览会自动应用配置，已有会话仍可查看与导出。设置保存在当前项目的 `extensions/cocos-performance-inspector/PITemp/capture-settings.json`。

## 报告与文件

点击“导出 HTML”或“导出 JSON”，报告直接保存到插件目录下的 **`extensions/cocos-performance-inspector/PITemp`**。目录会自动创建，每份报告使用独立文件名，面板状态栏会显示完整保存路径。

下表中的路径相对于插件目录。删除或替换插件目录前，请备份 `PITemp` 中的报告与采集设置。

| 文件 | 用途 |
| --- | --- |
| `PITemp/performance-时间戳-随机标识.html` | 离线阅读与分享分析结果 |
| `PITemp/performance-时间戳-随机标识.json` | 保存采集数据，通过“导入 JSON”重新查看 |
| `PITemp/capture-settings.json` | 保存面板中设置的采样间隔与调用栈开关 |

可先打开 [HTML 演示报告](docs/demo-report.html) 了解报告内容，或导入 [JSON 演示数据](examples/demo-report.json) 体验面板。演示文件使用合成数据。

## 环境与统计范围

- **运行环境**：Cocos Creator 3.8.x，通过 HTTP `localhost` 或 `127.0.0.1` 打开的本机浏览器预览，包括电脑浏览器的手机模拟模式。
- **接入范围**：自动采集用于浏览器预览，不注入正式构建。原生模拟器、真机、小游戏及局域网预览暂不支持自动接入。
- **内存数据**：JS 堆数据取决于浏览器是否提供 `performance.memory`；GPU 数据来自可用的引擎设备统计。面板中的“采集覆盖与限制”会显示当前环境的支持情况。
- **分析边界**：对象增长、监听累积、已销毁目标和内存趋势用于辅助定位问题；确认内存泄漏还需结合业务生命周期与浏览器堆快照检查引用关系。资源释放记录表示观察到的操作，不保证底层内存已回收。
- **对照采集**：保持操作、时长与采集设置一致。切后台、断点、CPU 限速和大量 Console 日志会影响测量结果，采集与上报本身也有开销。

详细操作与排查方法见 [使用指南](docs/USAGE.md)，实现方式见 [架构说明](docs/ARCHITECTURE.md)。

## 源码开发

开发环境需要 Node.js 18+。使用已构建的安装包时，无需执行以下命令。

```powershell
npm install
npm run build
npm test
npm run check:runtime -- "Creator安装目录/resources/resources/3d/engine"
npm run package
```

`build` 编译编辑器代码和浏览器采集脚本；`check:runtime` 根据指定 Creator 引擎的声明文件检查运行时 API；`package` 生成可直接安装的插件目录和 ZIP 文件：

```text
release/
  cocos-performance-inspector/
  cocos-performance-inspector.zip
```
